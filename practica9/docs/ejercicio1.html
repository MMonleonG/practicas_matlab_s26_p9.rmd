Ejercicio 1: Datos de estudiantes

2026-11-08

Este ejercicio consiste en el análisis de las variables cualitativas y cuantitativas a lo largo de un archivo csv.

Tablas de frecuencias

En primer lugar, he creado una serie de tablas de frecuencias con las funciones table(), prop.table(), y rbind(), a partir de los datos, incluyendo frecuencias absolutas y relativas, así como porcentajes. Para las variables cuantitativas he agrupado los datos en intervalos con la función hist() y he escogido como nombre de columna el mínimo del intervalo. Las variables son las siguientes:
